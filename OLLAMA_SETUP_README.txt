J.A.R.V.I.S. ONE-CLICK SETUP

Python is expected to already be installed. Setup checks for Python 3.13, 3.12, or 3.11 and creates a local .venv; it does not download/install Python itself.

1. Extract this ZIP to a normal folder such as C:\JARVIS.
2. Double-click setup_jarvis.bat and wait for it to finish.
3. Double-click START_JARVIS_WITH_OLLAMA.bat.
4. The launcher checks Ollama, pulls llama3.2 if needed, tests the model, then launches J.A.R.V.I.S.

If you previously had a failed setup, close the app and rename the .venv folder to .venv-old before running setup_jarvis.bat again.

If installation fails, take a screenshot of the entire error. This package cannot run commands on your PC automatically until you launch the batch file.
